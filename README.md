# A&M PARFUM

Модульный статический сайт каталога масляной парфюмерии.

## Архитектура

- `index.html` — семантический каркас страницы.
- `styles/foundation` — базовые токены и общие правила.
- `styles/blocks` — независимые BEM-блоки интерфейса.
- `scripts/data` — данные каталога.
- `scripts/core` — состояние и DOM-утилиты.
- `scripts/components` — независимые компоненты поведения.
- `scripts/app.js` — единая точка запуска.

Классы интерфейса используют BEM: `block__element--modifier`.
Состояния обозначаются служебными классами `active`, `open`, `show`.

## Стандарты кода

- Один файл отвечает за один блок или одну техническую задачу.
- Данные, отображение, состояние и обработчики событий разделены.
- Повторяемые значения вынесены в именованные константы.
- Публичные функции остаются короткими и выполняют одну задачу.
- Максимальная длина строки — 100 символов, отступ — два пробела.
- Правила редактора закреплены в `.editorconfig`.

## Локальный запуск

ES-модули требуют HTTP-сервер. Откройте папку через любой локальный static server, а не двойным кликом по `index.html`.
